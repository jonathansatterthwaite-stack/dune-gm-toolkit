Dune tools

The toolkit is now three desktop apps: build them with npm run build (see the README). For development you can also open each one here in the browser; they share their data through this browser's storage.

Character maker

Guided creator, character editor and list.

Lore

Compendium, Timeline, Galaxy map, Worlds, House.

GM tools

Dice, Conflict, NPCs, Scene, Hooks, Reference.

Data from the old single-page toolkit? Open export-browser-data.html in the browser you used, save the file, then use File › Import browser data… in any of the desktop apps.
